🚀 Como Programador com IA, venho construindo sistemas web, plataformas sob demanda e robôs de automação para resolver problemas reais de operação!

Utilizando Inteligência Artificial aplicada à engenharia de software para acelerar entregas com arquitetura sólida, desenvolvi três projetos que estão em operação:

🤖 1. DataSys AutoMove RPA (Python + FastAPI + Playwright + Pandas)
Robô com painel web que automatiza a transferência em lote de aparelhos por código IMEI dentro do ERP. O que antes exigia horas de digitação manual, o robô executa sozinho no navegador em segundos e gera o relatório final em Excel.

📦 2. StockFlow — Controle de Estoque Multi-Setor (Node.js + PostgreSQL + Firebase)
Sistema web em nuvem com duas interfaces dedicadas:
• Assistência Técnica: controle de retirada e devolução de insumos por técnico, fila de aprovação e contagem física;
• Setor de Faturamento: planilha web automatizada para controle de termos de garantia e embalagens com alertas visuais (🔴 REPOR, 🟡 ATENÇÃO e 🟢 OK).

🚛 3. HelpCar — Plataforma de Guincho & Assistência Veicular Sob Demanda (TypeScript + Node.js + Monorepo)
Ecossistema em produção comercial integrando App do Cliente, App do Prestador, Painel Administrativo e API central.
